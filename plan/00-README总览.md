# 10-16-decision-atlas 项目计划总览

**项目**：决策规则 → 可交互"决策宇宙"可视化 Skill（规则集编译 + 确定性求值 + 反事实路径差 + 阈值二分 + 单文件 HTML 交付）
**方法论**：ai-tool-project-sprint（数据先行 + 确定性内核 + 合成真值基准 + 零依赖单文件交付 + 可证伪断言）
**项目系列**：同系列新题（不参赛，发 GitHub；前作名称与业务领域按脱敏纪律不入公开仓，见「决策记录」品牌隔离项）
**命名约定**：本地目录 `10-16-decision-atlas`（`10-16`=2026-10-16 日期标签）；**GitHub 仓库名 = `decision-atlas`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`。
**定位宣言（v1）**：把一份 eligibility／风控／政策规则集（JSON/YAML）编译成**可点击走通、可反事实对比、可自动校验**的单文件 HTML 决策树——每个输出节点由规则引擎**确定性求值**，不是模型"画个大概"。做**会算的图**，不是**好看的图**。
