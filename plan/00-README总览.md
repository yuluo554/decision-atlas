## 承诺-证据台账

| 承诺项 | 素材来源 | 交付物内可达性 | 核验方式 | 状态 |
|---|---|---|---|---|
| 确定性规则引擎 | 用户提供的规则集（JSON/YAML）；引擎为纯 JS/Python 标准库自研 | 引擎随包，零第三方依赖 | 同输入重复运行**字节级一致**（sha256 断言）；引擎零规则字面量门禁 | ⬜ 待 M2 |
| 单文件 HTML 渲染（零 CDN） | 内联 CSS/SVG/JS；tidy-tree 布局手写 | 单个 .html 文件，无外部资源 | 无网络请求断言；同规则集同布局（坐标可断言） | ⬜ 待 M3 |
| 反事实路径差可校验 | 同一引擎重算两次 | 交互层零判定逻辑 | 高亮分叉边集合 = `path(A) Δ path(A')`（可断言） | ⬜ 待 M4 |
| 阈值二分可证伪 | 每个数值条件二分搜索 | 临界点随 HTML 内嵌 | 临界点满足 `eval(v) ≠ eval(v+ε)`（单元测试） | ⬜ 待 M4 |
| schema 校验 | 内嵌 `__DECISION_GRAPH__` JSON 固定 schema | 校验器随包 | 节点数=规则数、每边对应一条件、无孤儿节点、每路径终止于叶子裁定 | ⬜ 待 M4 |
| 覆盖率自检 | 枚举规则组合（纯算法） | 报告随基准产出 | 报告不可达节点／矛盾规则／恒真条件 | ⬜ 待 M4 |
| 合成规则集真值基准 | 程序化生成 + 假业务场景白名单 + 植入真值 | 基准零外部依赖、零 API | 一条命令复现；已知路径/临界点/不可达节点对账；指标口径进 README | ⬜ 待 M1/M4 |
| 单文件 HTML 示例产物 | 合成规则集编译产出 | GitHub Release 附示例 .html | 下载后可离线打开、可点击走通 | ⬜ 待 M5/M6 |
