# 06-里程碑详表

**状态**：M0 落盘（2026-10-15）；M1 完成（2026-10-15）。**作用**：每棒的目标、交付物（文件级）、**可演示面**（保证任何时刻停下都有可用物）、DoD 逐项、主要风险。

**纪律**（每棒生效）：
- 收尾顺序固定：**DoD 验证 → plan/00·05/06 状态回写 → 写 `plan/HANDOFF-M<next>.md`（六节）→ commit →（有远端则 push 等 CI 绿）**；HANDOFF 未落盘不得结束对话。
- 未推送 = 未跑 CI：CI 类 DoD 一律写"**本地等价校验（未接远端，CI 待首推验证）**"，并列出可指认的替代证据与缺口；M6 首推后据实补记真实结论（不美化、不预填）。
- 阻塞在用户动作时：更新当前 HANDOFF 待办区 + 续接指针，不写虚构的 next。

## M2 确定性内核（引擎 + 反事实 + 阈值二分）（下一棒，见 HANDOFF-M2）

- **目标**：求值语义内核完成：引擎全量（tree+list）、反事实 Δ、阈值二分、YAML 子集、确定性门禁。
- **交付物**：`src/engine.js`（完成）、`src/counterfactual.js`、`src/bisect.js`、`src/yaml.js`、`src/graph.js`（list→tree）；测试：引擎字节级一致、list/tree 等价、Δ 集合等式、bisect 证据对、YAML 子集正反例、**零规则字面量门禁**（含 `--selftest` 阳性对照）。
- **可演示面**：`node tools/atlas.js walk rules.json --case case.json` 打印 trace；`node tools/atlas.js bisect …`（或 walk 附阈值面板数据）展示 v*/v*+ε 证据对。
- **DoD**：
  1. 同输入双跑 sha256 相等（引擎级断言）；
  2. 零规则字面量扫描 0 命中 + 探活（故意植入阈值 → 必红）；
  3. 反事实：高亮集合 == `path(A) Δ path(A')`（双向包含断言）；
  4. 阈值：每条报告边界满足 `g(a*) ≠ g(b*)` 且 `b*-a* ≤ ε`；粗扫+细二分两段独立复现；
  5. YAML 子集样例通过；越界语法显式报错（exit 2）；
  6. 本地等价校验全绿（未接远端，CI 待首推验证）。
- **风险**：bisect 边界语义（非单调）反复——缓解：不做单调假设、如实多报；YAML 子集范围失控——缓解：子集清单写进文档 + 正反例测试。

## M4 校验与基准（校验器 + 覆盖率 + 真值基准）

- **交付物**：`src/coverage.js`、`tools/validate.js`、`tools/bench.js`；测试：不变量断言（节点数=规则数/边=条件极性/无孤儿/叶子终止）、覆盖率与植入集合对账、基准四类指标、**每套件探活必红**、退出码三语义锁测试。
- **可演示面**：`node tools/validate.js out/demo-game.html` 校验报告；`node tools/bench.js` 一条命令出指标表（写 README）。
- **DoD**：
  1. 校验器 `--check` 模式：重渲染与产物逐字节比对（sha256）；
  2. 覆盖率 precision/recall 与植入集合对账（有分母有分子）；
  3. 基准指标达标（门槛随 manifest；达标值以末态回填 README）；
  4. 探活：注入缺陷 → 必报未达标（每个套件逐个验证）；
  5. 本地等价校验全绿（未接远端，CI 待首推验证）。
- **风险**：覆盖率对复合条件过保守（缓解：如实标 unknown，宁少报不假报）；探活"期望同源"假红（缓解：期望锚定冻结真值库）。
