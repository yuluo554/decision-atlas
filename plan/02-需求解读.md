## 一、痛点 → 能力转译

| 业务方痛点（题面 §一） | 转译能力 | 可证伪判据（不是"看起来对"） |
|---|---|---|
| 读规则文本答不了"输入落在哪条路径、裁定是什么" | **确定性求值**：引擎逐条布尔求值 + 走通路径（节点序列+边序列）+ 最终裁定 | 同输入重复运行字节级一致（canonical JSON 的 sha256 相等） |
| 答不了"改一个字段会不会翻盘、从哪条边分叉" | **反事实路径差**：同一引擎重算 + 高亮分叉边集合 | 高亮集合 == `path(A) Δ path(A')`（集合相等断言） |
| 答不了"数值条件的临界点到底是多少" | **阈值二分**：每个数值条件二分搜索临界值 | 临界点满足 `eval(v*) ≠ eval(v*+ε)`（逐点复核断言） |
| "AI 画图"会画错/边界会飘/反事实靠猜 | **编译器语义**：坐标由算法算、裁定由引擎算；模型只做表达层 | 布局双跑坐标相等；引擎零规则字面量扫描 0 命中 |
| "图看着对，但没法验证" | **校验器 + 真值基准**：schema 断言 + 覆盖率自检 + 合成真值对账 | 节点数=规则数、每边对应一条件极性、无孤儿、叶子终止；基准一条命令复现 |

## 三、边界与非目标

（继承《01-题目文档》§六，逐条落地为可执行的"不做"清单）

1. **不做规则集创作**：规则集由用户提供；本工具是编译器/可视化器，不是规则生成器。模型只做解读与歧义澄清（表达层），不替用户发明规则。
2. **不做"AI 画图"**：坐标必须算法生成（tidy 布局 / 未来网格扫描），**模型永不产出坐标、永不产出裁定结果**。
3. **不承诺视觉美观超越 archify**（84248★，2026-10-16 复测）：差异化在**求值**而非美观。
4. **隐私红线**：纯本地处理，规则集与案例**不上传**、不调用外部 API、零网络请求；单文件 HTML 无 CDN、无外部资源。
5. **品牌隔离**：不复制姊妹项目代码；公开文档不提及其余项目业务领域（文档内一律用方向级描述）。
6. **首期范围限定**：决策树 + 反事实 + 阈值二分为主；决策边界图、多规则集对比、SVG/PNG 导出列扩展。
7. **数值口径**：不写会随实现漂移的硬数字（引擎规模写"核心求值内核约百行量级、`src/` 全量以末态回填"；节点数/测试数"以末态回填"）；数值阈值**一处定义（规则集）、多处引用**；合成基准指标口径与门槛写进 manifest/README，不写死通过数。
8. **追加边界（M0）**：
   - v1 **不承诺 YAML 全语法**，只承诺文档化子集 + 显式报错（D-03）；
   - 目标浏览器为现代 Chromium/Firefox/Safari；不承诺旧浏览器兼容；产物以 **file:// 直接打开**为一等场景；
   - 本工具**不产生判定建议以外的业务合规承诺**：裁定=规则集机械求值结果，工具对其正确性的承诺以"可证伪断言"为限（这是工程题，不是法务/医疗意见）。

## 四、可证伪承诺表

| # | 承诺（题目语言） | 证伪方式（机器可查） | 落点 |
|---|---|---|---|
| C-1 | 求值确定性：同输入重复运行**字节级一致** | 引擎双跑 canonical JSON 的 sha256 相等；CLI 级双跑产物 sha256 相等 | M2 |
| C-2 | 坐标由算法算、同规则集同布局 | 布局双跑坐标完全相等 + 结构不变量（父节点居中于子节点等）；渲染整文件字节一致 | M3 |
| C-3 | 反事实差异可校验 | 高亮分叉边集合 **==** `path(A) Δ path(A')`（集合等式断言，含合成真值中的已知反事实对） | M2 语义 / M4 对账 |
| C-4 | 阈值可证伪 | 对每个报告的临界点逐点断言 `eval(v*) ≠ eval(v*+ε)`；粗扫与二分两条独立路径互验 | M2 / M4 |
| C-5 | 输出 HTML 可 schema 校验 | 内嵌 `__DECISION_GRAPH__` JSON 断言：节点数=规则数、每边对应一条件极性、无孤儿节点、每路径终止于叶子裁定 | M4 |
| C-6 | 覆盖率自检（纯算法） | 枚举规则组合，报告不可达节点/矛盾规则/恒真条件；与真值库植入的已知集合对账 | M4 |
| C-7 | 零依赖、零外链、零网络请求 | 无 runtime 依赖清单；产物外链扫描 0 命中（白名单仅 SVG 命名空间 URI）；源码无 `fetch`/`XMLHttpRequest`/动态 `import(` | M3 |
| C-8 | 基准一条命令复现 | `node tools/bench.js`（退出码 0/1/2 语义锁进测试）；门槛随 manifest 下发；探活必红 | M4 |

## 五、用户旅程（验收场景，M5 全流程演练）

1. 用户拿到本仓库（clone 或 Release 包），**无需 npm install**（零依赖）；
2. 用户提供自己的规则集（JSON/YAML 子集）与一条案例；
3. `node tools/atlas.js build rules.json --case case.json -o atlas.html` 一条命令编译；
4. **file:// 直接打开** `atlas.html`：看到决策树（算法布局），初始案例的走通路径高亮、裁定清晰；
5. 点击/修改字段 → 引擎重算 → **分叉边高亮**、裁定翻盘即见；
6. 查看每个数值条件的**临界点与 ε 证据**（v* 与 v*+ε 两侧裁定不同）；
7. `node tools/validate.js atlas.html` 复验产物（schema 断言 + 覆盖率报告）；
8. `node tools/bench.js` 一条命令复现合成基准（已知路径/临界点/不可达节点对账）；
9. 全流程断网可跑；规则集不出本机。
