## 三、决策记录（M0 补记；并入 00 总表维护）

| 编号 | 决策 | 结论与理由 |
|---|---|---|
| D-01 | 引擎与工具链统一 JS | Node ≥20 + 现代浏览器共通子集；验证器为 `validate.js`。理由：交互求值必须浏览器内运行；单语言单口径；Node 内置测试。否决 Python 双路线（口径漂移源）、TS（构建链依赖） |
| D-02 | **零第三方依赖（含工具链）** | 测试 `node:test`；打包自研极简 bundler（约定受测试约束）；无 `npm install` 步骤。否决 vite/rollup/zod/jest 等 |
| D-03 | 输入格式 | JSON 为规范格式；YAML 承诺**文档化子集**（M2 手写解析器），越界语法显式报错、绝不猜测；子集范围 M1 冻结时定稿 |
| D-04 | 数据模型 | **树模式为主**（显式条件节点、分支 yes/no）；**列表模式**（有序规则、首命中生效）纳入 v1 规格作"编译"通道（list→tree，M2）。"节点数=规则数"口径据此定义 |
| D-05 | 条件模型 v1 | 原子 `{field,op,value}` + 递归 `all/any`；四类型（number/boolean/enum/string）+ 算子白名单；复合条件的覆盖率分析**保守处理**（宁少报不假报） |
| D-06 | 完整性与默认裁定 | tree 模式全树终止于裁定（无环/无悬空/无孤儿）；`"$default"` 哨兵可选；list 模式必填 `default_verdict`；case 必须完备（缺字段=报错，不猜） |
| D-07 | 退出码三语义 | `0` 成功 / `1` 内容校验失败 / `2` 用法或输入形态不可用（缺文件、坏 JSON、空文件）；锁进 CLI 测试 |
| D-08 | 确定性序列化 | canonical JSON（键按码点排序、无空白、非有限数报错）+ sha256；`src/`/`tools/` 禁 `Date.now`/`Math.random`；生成器用自研 splitmix64；产物无时间戳 |
| D-09 | 精度约定 | bisect ε = 1e-6、粗扫 N0 = 256（精度约定，非规则数值，豁免零字面量门禁）；数值字段 `search_range` 可选，缺失则跳过该场二分并如实报告 |
| D-10 | 布局 | v0 简易确定性（叶中序 + 中点回填）；M3 升级 tidy 精化；常量集中在 `src/layout.js`；坐标唯一产出点，模型不可改 |
| D-11 | 单文件 HTML 契约 | 预渲染 SVG + 内联引擎（bundle，非模块脚本，file:// 兼容）+ `__DECISION_GRAPH__` 内嵌 JSON（`<` 全转义）；零外链（白名单仅 w3.org 命名空间）；同输入双渲染逐字节一致 |
| D-12 | 许可与署名 | MIT；署名 `yuluo554`；GitHub 仓库名 `decision-atlas`（公开，M6 发布）；品牌隔离沿用 00 口径 |
